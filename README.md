# defold-wechat
This project is for testing and debugging features related to WeChat Mini Games, with different branches implementing different functionalities:

- **main branch**: Supports running on WeChat Mini Games, but cannot save game state.
- **sound branch**: Supports audio playback in WeChat Mini Games.
- **file branch**: Supports file system operations in WeChat Mini Games, enabling game state persistence.

ref: https://github.com/diiyw/dw

此项目是测试调试微信小游戏相关功能，不同分支有不同的功能
 - **main 分支**： 支持跑在微信小游戏上，但是不能保存游戏状态
 - **sound 分支**：支持微信小游的声音播放
 - **file 分支**： 支持微信小游的文件系统相关操作，游戏状态能保存

 关联项目： https://github.com/diiyw/dw
